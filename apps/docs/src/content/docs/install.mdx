Nembrix ships as a native desktop app for macOS, Windows, and Linux.
You can also run the web build for fast iteration.

## Desktop

<Tabs>
  <TabItem label="macOS">
    Download the latest `.dmg` from
    [Releases](https://github.com/oesukam/nembrix/releases), open it,
    drag the app into Applications.

    On first launch, macOS will ask you to confirm an unsigned
    developer — until we ship a notarized build, right-click the app
    → **Open**.
  </TabItem>
  <TabItem label="Windows">
    Download the `.msi` installer from
    [Releases](https://github.com/oesukam/nembrix/releases) and run it.
  </TabItem>
  <TabItem label="Linux">
    `.AppImage` and `.deb` builds are on the
    [Releases](https://github.com/oesukam/nembrix/releases) page.

    ```sh
    chmod +x Nembrix.AppImage
    ./Nembrix.AppImage
    ```
  </TabItem>
</Tabs>

## What you need

- A Postgres server you can reach (locally or over SSH).
- For SSH tunnels: ssh-agent set up, or a key file you can point us at.
- Nothing else. There's no required cloud account, no telemetry by
  default, no daemon.

## 0.1.0 — first release

The first public release of Nembrix: a multi-session, SSH-first Postgres
client with an editable result grid, a schema-aware SQL editor,
JavaScript scripting, `EXPLAIN ANALYZE`, schema tools, and CSV / JSON /
SQL import & export.

> **Pre-release (0.x):** the on-disk format and stored-secret keys may
> change between minor versions. Don't rely on it as your only client
> against production data yet.
